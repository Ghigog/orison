# Ticket Template

Copy this template to create new tickets in [backlog.md](backlog.md) or [in_progress.md](in_progress.md).

---

## Ticket Structure

Unique Identifier (like VA001) : Title (status)

**User story:**
* **As a** [user/system role]
* **I'd Like to** [perform action]
* **So that** [achieve business value]

**Context:** (why)
- [Add background information, design rationale, or links to references]

**Description:** (what)
- [Brief description of the feature or bug fix]

**Requirements:** (how)
- [Specific technical constraints, file modifications, or steps]

**Acceptance criteria:** (serves as basis for unit tests)
* **Given** [preconditions]
* **When** [actions/events trigger]
* **Then** [expected outcomes]
