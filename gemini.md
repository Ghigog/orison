# Gemini Agent Guide

This document assists AI agents (like Antigravity) in navigating the Orison codebase, finding relevant features, and keeping development modular.

## Agent Guidelines

1. **Keep Code Modular**: Keep scripts focused on specific systems (e.g., Parser, State Manager, UI). Avoid monolithic files.
2. **Document Feature Locations**: If a feature is implemented inside a shared script rather than having its own dedicated script, add or update its exact line range in the **Feature Map** below.
3. **Keep this File Updated**: Every time you implement, refactor, or delete a feature, update the Feature Map and/or files list below.
4. **Follow the Ticket System**: Check [docs/in_progress.md](file:///Users/dylangrowcoot/Documents/Personal Apps/orison/docs/in_progress.md) for current tasks. Move tickets between tracking files (`backlog.md` -> `in_progress.md` -> `done.md`) as status changes.
5. **Adhere to the Design System**: When developing or updating user interfaces, themes, or layouts, strictly follow the specifications outlined in the [Design Philosophy](file:///Users/dylangrowcoot/Documents/Personal Apps/orison/design_philosophy.md) system.
6. **Continuous Documentation Maintenance**: Keep core documentation (such as `README.md`, `ARCHITECTURE.md`, and technical guides) updated as you implement new systems, refactor existing files, or add features. Ensure that any prompt engineering details, state machines, or data structures are accurately detailed for future agents.
7. **Prefer Scene Files for UI**: For Godot projects, `.tscn` files with UI created dynamically as scenes should always be preferred over injecting UI elements through code. Ensure all UI elements are restrained within proper Control containers (like `MarginContainer`, `PanelContainer`, or aspect-ratio locked containers) so that their elements do not bleed out when window size changes. Make UI layouts fully responsive.

## Codebase Map

### Core Systems

- **Parser Engine**: Parses Obsidian markdown archives and player input formatting (`res://src/core/MarkdownParser.gd`, `res://src/core/VaultCompiler.gd`, `res://src/core/VaultScanner.gd`, `res://src/core/PlayerInputParser.gd`).
- **Story State Manager**: Coordinates game state, inventory updates, and saving/loading (`res://src/autoload/CampaignState.gd`, `res://src/core/SaveManager.gd`, `res://src/core/MemoryManager.gd`).
- **UI & Layout**: Controls viewport rendering, dialogue text scrolls, settings configurations, theme/font customization, and responsive visual layout maps (`res://scenes/ui/MainViewport.tscn`, `res://src/ui/MainViewport.gd`, `res://src/ui/VirtualScrollContainer.gd`, `res://src/ui/ChatMessageRow.gd`, `res://src/autoload/ThemeManager.gd`, `res://src/ui/SettingsModal.gd`, `res://src/ui/CharacterVisuals.gd`, `res://src/ui/MindMapModal.gd`, `res://scenes/ui/OnboardingFlow.tscn`, `res://src/ui/OnboardingFlow.gd`, `res://scenes/ui/onboarding/`, `res://src/ui/onboarding/`).
- **Tabletop/DND Ruleset**: Handles dice rolls, character stats, and rules checks (future implementation).
- **Emotion Engine**: Processes character emotional states and rapport changes (`res://src/core/EmotionEngine.gd`, `res://src/core/EmotionPromptBuilder.gd`).
- **AI Prompting & Clients**: Manages local LLM prompting, custom system instructions, response parsing, and image generation interfaces (`res://src/core/PromptBuilder.gd`, `res://src/core/SystemPrompts.gd`, `res://src/autoload/LLMClient.gd`, `res://src/core/JsonRepair.gd`, `res://src/core/LLMStreamRequest.gd`, `res://src/autoload/ImageGenClient.gd`, `res://src/autoload/ImageGenManager.gd`, `res://src/core/ProceduralArtEngine.gd`).
- **Media & Audio Coordinator**: Manages background music, voice clips, and AI generator stubs (`res://src/autoload/MediaManager.gd`).
- **Autoload Messaging**: Manages decoupled signals across modules (`res://src/autoload/EventBus.gd`).
- **Testing Suite**: Dynamic unit and integration test runner (`res://tests/TestRunnerNode.gd`, `res://tests/TestRunner.tscn`).
- **Semantic Retrieval** *(planned — RAG007)*: Hybrid BM25 + KNN semantic embedding retrieval using `nomic-embed-text` via Ollama and `sqlite-vec` GDExtension (`res://src/autoload/EmbeddingStore.gd`, `res://src/core/KnowledgeGraphManager.gd`).
